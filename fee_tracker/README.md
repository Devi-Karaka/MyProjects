**Fee Payment Tracker**

**Short description**

The Fee Payment Tracker automates student fee reminders, due-date notifications, and extension requests using SharePoint, Power Automate, Outlook, and Excel. It minimizes manual follow-ups, ensures timely payments, and provides mentors with real-time updates.

**Tools**

* Microsoft SharePoint (stores student and fee details)
* Power Automate (sends reminders, notifications, and processes extension requests)
* Outlook (delivers reminder emails and mentor updates)
* Excel (tracks payments and generates summary reports)

**What it does**

* Students receive automated reminders 3, 2, and 1 day before due date
* After due date, mentors are notified automatically
* Students can request extensions via a permission form (with reason and dates)
* Mentors approve/reject extension requests via email
* Admins track fee status and generate Excel reports

**How to import / view**

1. Open 'Exports/automateflow.zip' and import into Power Automate (My Flows → Import).
2. Open 'Exports/data.csv' and create a SharePoint list (or manually create lists using the column names in Documentation).
3. View 'Demo/project\_process.mp4' for a walkthrough.
