**# Newsletter Distribution System**

**Short description**

The Newsletter Distribution System automates the creation, scheduling, and distribution of newsletters using SharePoint, Power Automate, Outlook, and Excel. It streamlines communication, reduces manual effort, and ensures timely delivery of updates to all stakeholders.

**Tools**

* Microsoft SharePoint (stores newsletter content and recipient details)
* Power Automate (automates scheduling and distribution)
* Outlook (sends newsletters via email)
* Excel (manages recipient lists and engagement tracking)

**What it does**

* Content is uploaded to SharePoint for newsletters
* Power Automate retrieves content and recipient list
* Automated email newsletters are sent via Outlook
* Excel reports track delivery and engagement data

**How to import / view**

1. Open 'Exports/newsletterflow.zip' and import into Power Automate (My Flows → Import).
2. Open 'Exports/subscribers.csv' and create a SharePoint list (or manually create lists using the column names in Documentation).
3. View 'Demo/vedio.mp4' for a walkthrough.

**Files**
